# 📊 Business Analytics Dashboard

A responsive, web-based dashboard designed to visualize business performance through interactive charts. Built using HTML, CSS, JavaScript, and Chart.js, this project presents monthly revenue, expenses, profit, and expense distribution in a clean, professional interface.

**🚀 [Visit the Business Analytics Dashboard](https://revenuevisualizationdashboard.netlify.app/)**

## 📌 Project Overview

The Business Analytics Dashboard provides a visual representation of sample financial data, helping users understand business performance and explore financial trends.

The dashboard brings three visualizations together on a single page, making it easy to compare monthly financial figures and view expense distribution.

## ✨ Features

- 📈 **Revenue, Expenses & Profit:** Compare monthly financial performance using a line chart.
- 📊 **Monthly Revenue Analysis:** Visualize revenue from January to June using a bar chart.
- 🥧 **Expense Distribution:** View the illustrative allocation of expenses across different categories using a pie chart.
- 📱 **Responsive Design:** Automatically adapts to different screen sizes.
- 💰 **Indian Currency Formatting:** Displays revenue values using the ₹ symbol and Indian number formatting.
- 🎨 **Clean User Interface:** Features a modern layout, rounded chart cards, and subtle shadows.
- ⚡ **Interactive Visualizations:** Explore charts powered by Chart.js.

## 📊 Dashboard Visualizations

### 1. Revenue, Expenses & Profit

A line chart comparing revenue, expenses, and profit across six months: January, February, March, April, May, and June.

### 2. Monthly Revenue

A bar chart showing monthly revenue values, allowing users to compare performance across different months.

### 3. Expense Distribution — June

A pie chart illustrating the distribution of expenses across three categories:

- Reinvestment — 40%
- Salaries — 30%
- Miscellaneous — 30%

*These percentages are illustrative examples, not verified financial figures.*

## 🚀 Getting Started

### Run the Project Locally

**Step 1: Clone the repository**

```bash
git clone https://github.com/shivamarya-67531/Revenue-Visualization-Dashboard.git
```

**Step 2: Open the project folder**

```bash
cd Revenue-Visualization-Dashboard
```

**Step 3: Run the dashboard**

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

**Note:** An internet connection is required to load Chart.js from its CDN.
